# 진도관리

반별 진도 기록 · 교사 시간표 · 수업 자료 클라우드를 한 곳에서 관리하는 웹앱입니다.
로그인하면 PC, 노트북, 태블릿 어디서든 같은 데이터를 쓰고, 한 기기에서 바꾼 내용은 다른 기기에 바로 반영됩니다.

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| 오늘 수업 | 시간표에 따라 그날 수업이 자동으로 나옵니다. 차시를 고르고 메모와 자료를 붙여 기록합니다. 다음 차시는 자동으로 추천됩니다. |
| 반별 진도 | 과목별로 반마다 몇 차시까지 나갔는지, 어느 반이 몇 차시 뒤처졌는지 비교합니다. 반별 수업 기록을 보고 CSV로 내보낼 수 있습니다. |
| 시간표 · 반 | 수업하는 반(예: 2-3 국어)을 추가하고 주간 시간표 칸에 배치합니다. |
| 단원 · 차시 | 과목별 단원과 차시 목록을 만듭니다. 여러 줄을 한 번에 붙여넣을 수 있습니다. |
| 수업 자료 | 파일을 올리고 과목 · 차시별로 분류합니다. 어느 수업에 썼는지도 함께 보입니다. |
| 설정 | 하루 교시 수, 토요일 수업 여부, 휴업일, 데이터 백업, 로그아웃 |

## 같은 수업을 여러 반에서 할 때 (차시를 미리 안 짜도 됨)

1. 그 수업을 처음 하는 반의 카드에서 **+ 새 차시** 를 눌러 차시를 만듭니다.
2. **자료 첨부** 에서 '차시에 붙이기'로 파일이나 링크를 올리고 **진도 기록** 을 누릅니다.
3. 다음 반 카드에는 그 차시가 자동으로 선택되어 있고 자료도 이미 붙어 있습니다. **진도 기록** 만 누르면 됩니다.

자료는 반이 아니라 차시에 한 번만 붙이면 됩니다. 특정 반에만 필요한 자료(예: 그 반 활동 결과물)는 첨부할 때 '이 반 수업에만 붙이기'를 고르세요.

## 처음 설정하기 (약 10분)

### 1. Supabase 프로젝트 만들기
1. https://supabase.com 에 가입하고 **New project** 를 누릅니다.
2. 이름과 DB 비밀번호를 정하고, Region 은 **Northeast Asia (Seoul)** 을 고릅니다.

### 2. DB 만들기
1. 왼쪽 메뉴 **SQL Editor** 를 엽니다.
2. 이 폴더의 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run** 을 누릅니다.

### 3. 내 계정 만들기
1. **Authentication → Users → Add user → Create new user**
2. 이메일과 비밀번호를 입력하고 **Auto Confirm User** 를 체크한 뒤 만듭니다.
3. 다른 사람이 가입하지 못하도록 **Authentication → Sign In / Providers** 에서 **Allow new users to sign up** 을 끕니다.

### 4. 앱에 연결하기
1. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키를 복사합니다.
2. `js/config.js` 파일에 붙여넣습니다.

```js
export const SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

anon 키는 브라우저에 공개되도록 만들어진 키라 노출되어도 괜찮습니다. 데이터는 행 단위 보안(RLS)으로 로그인한 본인만 볼 수 있습니다.

## 실행하기

### 내 PC에서 바로 열기
이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 http://localhost:5500 을 엽니다.

```bash
python -m http.server 5500
```

(`index.html` 을 더블클릭해서 열면 동작하지 않습니다. 반드시 위처럼 서버로 열어야 합니다.)

### 여러 기기에서 쓰기 (무료 배포)
아래 둘 중 하나를 고르면 어디서든 접속할 수 있는 주소가 생깁니다.

- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 끝입니다.
- **GitHub Pages**: GitHub 저장소에 올리고 Settings → Pages 에서 배포합니다.

빌드 과정이 없는 정적 파일이라 폴더 그대로 올리면 됩니다.

## 알아둘 점

- **저장 용량**: Supabase 무료 플랜은 파일 저장 1GB, 파일 1개당 50MB 까지입니다. 큰 동영상은 Google Drive 등에 올리고 **링크 추가** 로 붙이세요.
- **무료 플랜 일시정지**: 1주일 동안 접속이 없으면 프로젝트가 일시정지됩니다. 대시보드에서 Restore 를 누르면 데이터 그대로 다시 켜집니다.
- **개인정보**: 학생 이름이나 성적 같은 개인정보는 넣지 않는 것을 권장합니다.
- **백업**: 설정 → 백업 파일 내려받기로 기록 전체를 JSON 파일로 저장할 수 있습니다.

## 단원 · 차시 한 번에 입력하는 형식

```
# 1. 문학과 삶
시의 운율과 심상
소설의 시점과 거리
# 2. 언어와 매체
음운의 변동
```

`#` 으로 시작하는 줄은 단원 이름이고, 나머지 줄은 차시 하나씩입니다. 엑셀에서 `단원 | 차시` 두 열을 복사해 붙여넣어도 됩니다.

## 파일 구조

```
index.html            앱 진입점
css/style.css         스타일
js/config.js          Supabase 연결 정보 (직접 입력)
js/app.js             로그인 · 메뉴 · 화면 전환
js/store.js           데이터 불러오기 · 저장 · 실시간 동기화
js/views/*.js         화면별 코드
supabase/schema.sql   DB 테이블 · 보안 정책 · 파일 저장소 설정
```
