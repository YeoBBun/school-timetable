# 진도관리

반별 수업 기록 · 교사 시간표 · 수업 자료를 한 곳에서 관리하는 웹앱입니다.
**구글 계정으로 로그인**하고, 모든 기록과 수업 자료는 **내 구글 드라이브의 `진도관리` 폴더**에 저장됩니다.
따로 서버나 DB가 없고, 같은 구글 계정이면 학교 · 집 어디서든 같은 화면이 나옵니다. 다른 기기에서 바꾼 내용은 30초 안에(또는 창으로 돌아올 때) 반영됩니다.

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| 오늘 | **오늘 시간표**와 **담당 반 목록**. 반마다 단원을 고르고 한 일을 한 줄 적은 뒤 Enter 를 누르면 기록됩니다. 기록에 파일을 끌어다 놓으면 자료가 붙습니다. 반 메모(예: 활동지 안 걷음)도 여기서 씁니다. |
| 찾기 | 수업 기록 · 자료 · 반 메모를 학년도와 상관없이 검색합니다. 단원별로 모아 볼 수도 있습니다. |
| 수업 자료 | 학기마다 단원별 · 수업/평가별로 자료를 정리합니다. 단원 만들기 · 이름 바꾸기도 여기서 합니다. |
| 수행평가 | 학기 · 과목 · 학년별로 수행평가를 만들고 반마다 평가일을 넣습니다. 점수는 표에 입력하고(Enter 로 다음 학생) 엑셀로 내려받습니다. |
| 일정 | 수행평가 날짜와 수업 관련 일정을 모아 봅니다. 구글 캘린더에 연결하면 '진도관리' 캘린더로 자동으로 보냅니다. |
| 시간표 · 반 | 올해 담당 반을 추가하고, 반을 고른 뒤 시간표 칸을 클릭하거나 드래그해서 칠합니다. 지난 학년도 반도 여기서 볼 수 있습니다. |
| 설정 | 하루 교시 수, 토요일 수업, 2학기 시작일, 휴업일, 백업, 로그아웃 |

반 이름을 누르면 반 화면이 열립니다. 탭: **수업 기록**(CSV 내려받기) · **학생**(직접 입력 · 붙여넣기 · 나이스 명렬표 엑셀, 학생 메모) · **수행평가** · **조 편성** · **칭찬 스티커**.
첫 화면 반 칸의 👥 는 조 편성, ⭐ 는 칭찬 스티커 TV 화면입니다.

## 조 편성

조 수 또는 조 인원을 고르고 **조 짜기**를 누르면, 아래 조건을 최대한 지키도록 자동으로 나눕니다.
붙이기 · 떼어 놓기 짝 규칙, 성별 고르게, 수준 고르게(학생 탭의 상 · 중 · 하), 지난 조와 덜 겹치게(최근 3번), 오늘 빠지는 학생 빼기, 조장(무작위 · 수준 높은 학생).
결과에서 학생을 끌어다 다른 조로 옮길 수 있고, 저장한 조는 **📺 크게 보기**로 TV 에 띄우거나 칭찬 스티커 조별 모드에서 씁니다.

## 칭찬 스티커

**⭐** 또는 반 화면 **칭찬 스티커 → 📺 칭찬 스티커 띄우기**를 누르면 TV 용 큰 화면이 열립니다. 학생(또는 조)을 누르면 +1, **↶ 되돌리기**로 취소합니다. 이유 버튼(발표 · 협동 등)은 고쳐 쓸 수 있고, 개수는 학기마다 따로 셉니다.

## 구글 캘린더 연결 (선택, 한 번만)

1. https://console.cloud.google.com → 진도관리 프로젝트
2. **API 및 서비스 → 라이브러리** → **Google Calendar API** → **사용**
3. **Google 인증 플랫폼 → 데이터 액세스 → 범위 추가 또는 삭제** → `calendar.app.created` 체크 → **업데이트** → **Save**
4. 앱의 **일정** 화면에서 **구글 캘린더 연결** → 구글 창에서 캘린더 항목 체크

앱은 자기가 만든 '진도관리' 캘린더만 다룰 수 있고, 다른 캘린더는 볼 수 없습니다.

## 자료는 드라이브에 자동으로 정리됩니다

앱으로 올린 파일은 `진도관리/수업 자료/2026학년도/2학기/단원 이름/수업(또는 평가)/` 폴더에 들어갑니다.
같은 자료를 다른 반에도 쓰면 복사하지 않고 연결만 합니다(기록의 **⇉ 다른 반에도 쓰기**를 쓰면 자료도 함께 붙습니다).

⚠️ 앱은 보안상 **앱으로 올린 파일만** 볼 수 있습니다. 드라이브 웹에서 직접 넣은 파일은 앱에 보이지 않으니 자료는 앱으로 올려 주세요.

## 학년도가 바뀔 때

학년도는 3월 1일에 시작합니다. 새 학년도에는 **시간표 · 반** 에서 새 반을 추가하고 시간표를 다시 칠하면 됩니다.
지난 반은 **지우지 마세요**. 자동으로 '지난 학년도 반'으로 넘어가고, 그 반의 기록과 자료는 **찾기**에서 계속 볼 수 있습니다.

## 시간표가 바뀌는 날 (교체 · 보강 · 결강)

**오늘** 화면에서 그 날짜로 이동한 뒤 **이날 시간표 바꾸기** 를 누르고, 바뀌는 교시만 고르면 됩니다.
그날만 바뀌고 다른 주에는 영향이 없습니다. 예정된 변경은 **시간표 · 반** 화면 오른쪽에 모여 보입니다.

## 처음 설정하기 (약 10분, 한 번만)

앱이 내 구글 드라이브를 쓸 수 있도록 Google Cloud 에서 **OAuth 클라이언트 ID** 를 하나 만듭니다. 무료입니다.

1. https://console.cloud.google.com 에 개인 Gmail 계정으로 들어가 **새 프로젝트** 를 만듭니다. (이름: 진도관리)
2. **API 및 서비스 → 라이브러리** 에서 **Google Drive API** 를 찾아 **사용** 을 누릅니다.
3. **Google 인증 플랫폼**(OAuth 동의 화면) → **시작하기**
   - 앱 이름: 진도관리, 사용자 지원 이메일: 내 Gmail
   - 대상: **외부**, 연락처: 내 Gmail → 만들기
4. **대상** → **테스트 사용자 → Add users** 에 내 Gmail 주소를 추가합니다.
5. **클라이언트 → 클라이언트 만들기**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `http://localhost:5500` 과 (배포한다면) `https://yeobbun.github.io`
   - 만들기 → **클라이언트 ID**(`…apps.googleusercontent.com`)를 복사합니다.
6. `js/config.js` 에 붙여넣습니다.

```js
export const GOOGLE_CLIENT_ID = '1234567890-abcdefg.apps.googleusercontent.com';
```

클라이언트 ID 는 공개되어도 괜찮은 값입니다. 앱이 요청하는 권한은 `drive.file` 하나로, **앱이 만든 파일과 폴더에만** 접근할 수 있고 드라이브의 다른 파일은 볼 수 없습니다.

처음 로그인할 때 "Google에서 확인하지 않은 앱" 화면이 나오면 **계속** 을 누르세요. 내가 만든 개인용 앱이라 그렇습니다.

## 실행하기

### 내 PC에서 바로 열기
이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 http://localhost:5500 을 엽니다.

```bash
python serve.py
```

(`index.html` 을 더블클릭해서 열면 동작하지 않습니다. 반드시 위처럼 서버로 열어야 합니다.)

### 여러 기기에서 쓰기 (무료 배포)
배포하면 어디서든 접속할 수 있는 주소가 생깁니다.

- **GitHub Pages**: 저장소 Settings → Pages 에서 `main` 브랜치를 고르면 `https://yeobbun.github.io/school-timetable/` 로 열립니다. 이 주소의 원본(`https://yeobbun.github.io`)을 OAuth 클라이언트의 승인된 JavaScript 원본에 꼭 추가하세요.

빌드 과정이 없는 정적 파일이라 폴더 그대로 올리면 됩니다.

## 알아둘 점

- **저장 위치**: 내 드라이브의 `진도관리/진도관리-데이터.json`(모든 기록)과 `진도관리/수업 자료/`(올린 파일). 이 파일과 폴더의 이름을 바꾸거나 지우지 마세요.
- **저장 용량**: 구글 드라이브 용량(무료 15GB)을 그대로 씁니다.
- **다시 연결**: 구글 로그인은 약 1시간마다 만료됩니다. 왼쪽 아래에 **다시 연결** 버튼이 나오면 눌러 주세요. 그동안 고친 내용은 연결되면 이어서 저장됩니다.
- **동시에 고치기**: 두 기기에서 같은 항목을 거의 동시에 고치면 나중에 고친 쪽이 남습니다. 서로 다른 항목은 둘 다 남습니다.
- **자료 삭제**: 앱에서 자료를 지우면 파일은 드라이브 휴지통으로 가서 30일 동안 되살릴 수 있습니다.
- **개인정보**: 학생 이름이나 성적 같은 개인정보는 넣지 않는 것을 권장합니다.
- **빠른 시작**: 마지막으로 본 데이터를 이 PC 브라우저에 사본으로 남겨 두어, 켜자마자 화면이 뜨고 드라이브와는 뒤에서 맞춥니다. 다른 사람 PC에서 썼다면 꼭 **설정 → 로그아웃**을 눌러 주세요(사본도 함께 지워집니다).
- **백업**: 설정 → 백업 파일 내려받기로 기록 전체를 JSON 파일로 저장하고, 백업 파일 불러오기로 되살릴 수 있습니다.

## 단원 · 차시 한 번에 입력하는 형식

```
# 1. 문학과 삶
시의 운율과 심상
소설의 시점과 거리
# 2. 언어와 매체
음운의 변동
```

`#` 으로 시작하는 줄은 단원 이름이고, 나머지 줄은 차시 하나씩입니다. 엑셀에서 `단원 | 차시` 두 열을 복사해 붙여넣어도 됩니다.

## 파일 구조

```
index.html            앱 진입점
css/style.css         스타일
js/config.js          구글 OAuth 클라이언트 ID (직접 입력)
js/google.js          구글 로그인 · 드라이브 API
js/app.js             로그인 화면 · 메뉴 · 화면 전환
js/store.js           데이터 저장 (드라이브 파일) · 기기 간 동기화
js/views/*.js         화면별 코드
```
